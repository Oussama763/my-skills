# My Skills

## What for?
Skills are directories with structured files that you add in your prompts to guide the AI agent through a specific task.

This repo is going to be the place where I include every "skill" I feel like I frequently need in my prompts.


## Usage
You need to have `npx` on your computer (install it if you don't)

1. Go to your CLI and type this:
```bash
npx skills add Oussama763/my-skills
```

2. Pick the skill you want to add (currently I only have one skill and I just started working on it)

3. Pick the agent you want to use it with (claude code, github copilot, ...)

4. Pick Global or Local installation (Global recommended, allows you to use the skill inside any project in your home directory)

5. Finish the installation
